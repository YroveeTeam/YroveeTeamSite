# YroveeLauncher

Свой лаунчер для Minecraft: Fabric, Forge, Quilt, NeoForge, моды и шейдеры с
Modrinth, сборки (.mrpack), серверы, бэкапы миров, аккаунты Microsoft и
оффлайн, красивый тёмный интерфейс.

- **Сайт с описанием и кнопкой «Скачать»** — этот репозиторий раздаёт его через
  GitHub Pages: `https://ТВОЙ_НИК.github.io/ИМЯ_РЕПО/`
- **Скачать лаунчер** — раздел [Releases](../../releases/latest): файл
  `YroveeLauncher-Setup.exe`
- **Сборка из исходников** — папка `launcher`: запусти `build_exe.bat` (нужен
  Python 3.10+, детали в `launcher/СБОРКА_EXE.txt`)

Лаунчер не связан с Mojang и Microsoft. Работает в оффлайн-режиме и с
лицензионными аккаунтами: он не взламывает игру, а скачивает файлы с серверов
Mojang и запускает их.

# Сайт YroveeLauncher

Обычная статичная страница: `index.html` + `data.js` + папка `assets`. Бэкенд не нужен, хостинг бесплатный.

## Что менять
Только `data.js`: версия, ссылка на скачивание, возможности, таблица версий, список изменений, FAQ.
Выпустил обновление — добавь блок в начало `changelog`, поправь `version`, залей файлы заново.

## Как выложить бесплатно (самый простой способ — GitHub Pages)
1. Создай аккаунт на github.com и новый репозиторий (например, `YroveeLauncher`).
2. Загрузи в него содержимое этой папки (кнопка Add file → Upload files).
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту сайт будет по адресу `https://ТВОЙ_НИК.github.io/YroveeLauncher/`.
5. В `data.js` замени `ТВОЙ_НИК` в ссылках на свой ник. Сам лаунчер (zip) выкладывай в раздел Releases репозитория — ссылка «Скачать» ведёт именно туда.

Альтернативы, тоже бесплатные: Cloudflare Pages, Netlify (перетащи папку в окно браузера).
Свой домен (например, yrovee.ru) — платный, но можно подключить позже к любому из них.
